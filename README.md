# Mentor Scoring System - README


## Description
This project evaluates and ranks mentors on the basis of their engagements with their respective mentees, the progress of mentees and feedbacks received. It runs the code and creates a csv file that ranks the mentors on the basis of their Mentor Score.

---

## Basic Project Structure
```
mentors.csv
students.csv
interactions.csv
feedbacks.csv
main.py
mentor_scores.csv (output)
```

---

## Additional files
```
README.md
Ideation_doc.pdf
```

---

## How to run
1. Ensure that all the files are in the same directory as `main.py`.
2. Run the following command in terminal
    ```
    python3 main.py 
    ```
3. The output will be generated as a file named `mentor_scores.csv`.
